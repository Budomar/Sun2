# ☀️ Интерактивная Солнечная система

Интерактивная обучающая демонстрация Солнечной системы, созданная с использованием React, TypeScript, Vite и Tailwind CSS.

## 🚀 Возможности

- **Анимированные орбиты** — все 8 планет вращаются вокруг Солнца с реалистичными относительными скоростями
- **Интерактивность** — нажмите на планету, чтобы увидеть подробную информацию
- **Информационная панель** — название, диаметр, расстояние от Солнца, орбитальный период, количество спутников
- **Управление анимацией** — кнопки воспроизведения/паузы
- **Регулировка скорости** — 6 уровней скорости (0.25x – 10x)
- **Боковая панель** — быстрый доступ к любой планете
- **Адаптивный дизайн** — корректно отображается на разных экранах
- **Визуальные эффекты** — звёздное небо, кольца Сатурна, свечение планет

## 🛠 Технологии

- **React** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS** — стилизация

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```
